# MSTest AreEquivalent

This solution contains samples for the [Deep Object Comparison in MSTest with Assert.AreEquivalent](http://lronaldbosma.github.io/blog/2026/07/09/deep-object-comparison-in-mstest-with-assert.areequivalent/) blog post.

- All AwesomeAssertion tests should succeed because it's most feature complete.
- Two MSTest test fail because it doesn't support ignoring properties yet.
- Six Shouldly tests fail because it doesn't support ignoring properties and comparing objects of different types.
